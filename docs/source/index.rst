Toy Model
=================================

A simplified kinetic model (i.e. toy model) for phosphoryl-transfer reactions of the different oxygen isotopologues and isotopomers of the four species.

.. note::

   If you use Toy Model, please cite the original article and the corresponding `Zenodo version <https://zenodo.org/records/>`_:
   
   Nora M. Bernet, Nemo A. Schmalz, Enric Petrus, Federica Tamburini, Thomas B. Hofstetter. ChemRxiv, 2026, `(DOI) <https://doi.org/>`_
